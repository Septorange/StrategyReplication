# Strategy Lab V0.5 · Research Workstation
## 产品与交互设计说明

> 文档性质：产品设计 / 交互设计 / 研究工作流定义  
> 当前基准：**V6 Audited Baseline**  
> 当前状态：V6 数据链、Snapshot、FastAPI、Mode B 真引擎调用均已独立审计通过；本文件不修改 V6，不重新定义策略规则。  
> 目标：把当前“V6 回测结果查看器”升级为一个真正可用于策略研究、事件分析、收益归因和反事实实验的研究工作台。

---

# 0. 产品定位

当前版本已经解决：

```text
V6 formal outputs
→ Web Snapshot
→ FastAPI
→ Frontend
```

并已具备：

```text
Mode A：真实 V6 复盘
Mode B：真实 V6 Python 引擎参数实验
```

因此 V0.5 不再把主要资源投入“继续证明 V6 正确”，而是集中解决：

> **研究者面对一个策略问题时，能否在网站里快速找到证据、解释原因并进行反事实比较。**

---

# 1. V0.5 核心研究问题

任何 V0.5 页面或功能，都必须至少回答以下四类问题之一。

## Q1. 为什么今天这样持仓？

```text
为什么某资产入选 / 被剔除？
为什么基础仓位是这个数？
Cap 是否约束？
haircut 是否触发？
执行层为什么不是理论目标？
10VT 为什么是这个倍率？
最终仓位如何形成？
```

## Q2. 这一段收益或回撤是谁造成的？

```text
哪一类资产贡献最大？
哪一个品种贡献最大？
成本损耗来自哪里？
回撤期和正常期的结构有何差别？
```

## Q3. 策略什么时候发生了关键决策？

```text
什么时候换了动量入选资产？
什么时候触发 haircut？
什么时候 midmonth rebalance？
什么时候 10VT 撞 floor？
什么时候发生 roll？
```

## Q4. 如果改变一条规则，会发生什么？

```text
收益 / 风险变了多少？
哪些日期的仓位发生变化？
哪些资产变化最大？
10VT、换手、成本、回撤的变化来自哪里？
```

# 2. 产品原则

## 2.1 Research-first

优先级：

```text
解释策略
> 找到异常
> 比较反事实
> 漂亮展示
```

不得为了视觉效果牺牲字段语义。

## 2.2 One source of truth

正式模式的数据必须来自：

```text
V6 / future version engine
→ Snapshot / Experiment outputs
→ API
→ UI
```

禁止在浏览器重新实现策略。

## 2.3 Explain before compare

不要只告诉用户：

```text
V6 final weight = 24.8%
Experiment = 29.5%
```

必须能进一步回答：

```text
差异发生在哪一层？
Momentum？
Risk budget？
Haircut？
Execution？
10VT？
```

## 2.4 Preserve time semantics

必须清晰区分：

```text
当前收盘理论目标
冻结/受控目标
start-of-day execution weight
pre-10VT execution weight
final weight
```

不能把当天收盘才形成的 target 用于解释同日收益。

## 2.5 Audit-aware

关键指标、关键字段、关键规则，应能查看：

```text
来源
语义
时间点
Snapshot 字段
V6 原始字段
审计状态
```

展示：

```text

```

\[

\]

\[

\]

必须显示真实数值代入。

## Step 4 · Sleeve Scale

展示：

```text

```

```text

```

## Step 5 · Cap

展示：

```text

```

```text

```

## Step 6 · Volatility Haircut

展示：

```text

long_vol
historical threshold
triggered
haircut multiplier

```

## Step 7 · Execution

必须同时展示：

```text
Current-close theoretical target
controlled_target
unscaled_execution_weight
monthly_smoothing_step
midmonth_trigger
```

并明确：

```text
CLOSE target
≠
same-day start-of-day executed weight
```

```text

25% / 50% / 75% / 100%
```

如果 midmonth：

```text

threshold
trigger at close
effective next trading day
```

## Step 8 · 10VT

展示：

```text
portfolio_vol_estimate
raw multiplier
final multiplier
floor/ceiling state
```

公式：

\[
m_t=clip\left(\frac{0.10}{\sigma_{120,t}},0.5,1.5\right)
\]

必须明确：

```text
prior-only
120D
ddof=1
sqrt252
```

## Step 9 · Final Weight

```text
pre10vt_weight
× final_10vt_multiplier
= final_weight
```

## Step 10 · Daily PnL

# 25. V0.5 最低验收标准

## Decision Explorer

- [ ] 任意正式交易日可选择；
- [ ] 任意 11 个资产可选择；
- [ ] 完整显示 eligibility → momentum → RB → scale → cap → haircut → execution → 10VT → final → PnL；
- [ ] 所有字段来自真实 V6 snapshot/API；
- [ ] current-close target 与 start-of-day weight 明确区分；
- [ ] 点击公式能查看真实代入数值。

## Event Explorer

- [ ] 至少支持 Performance / Risk / Execution / Roll 四类；
- [ ] 事件自动从数据生成；
- [ ] 支持筛选；
- [ ] 点击事件能跳转 Decision Explorer；
- [ ] Event date 保留在全局 Context。

## Attribution Explorer

- [ ] 支持 single day / custom range；
- [ ] Class → Asset 两层 drill-down；
- [ ] roll cost / rebalance cost 单列；
- [ ] 区间贡献不与简单累计收益混淆；
- [ ] 支持至少 Top Drawdown 选择。

## Execution & Roll

- [ ] 能查看 asset roll history；
- [ ] 三类 roll 规则分开展示；
- [ ] roll event inspector 完整；
- [ ] t 日旧合约 / t+1 新合约时序清楚；
- [ ] TF/T 不显示全局 no rollback。

## Experiment Lab

- [ ] 使用真实 V6 engine；
- [ ] 显示运行状态；
- [ ] 输出 KPI delta；
- [ ] 输出 exposure / 10VT / turnover / cost delta；
- [ ] 自动找 top changed days；
- [ ] 能打开 A/B Decision Compare；
- [ ] 浏览器不进行策略重算。

## Version-ready

- [ ] 前端核心组件接收 `strategyVersion`；
- [ ] 新增 API 不把 V6 硬编码在 UI 组件内部；
- [ ] Version Compare 页面可显示 V6 Audited；
