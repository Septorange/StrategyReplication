## 已复现的实质阻断

1. **跨快照直接比较违反强制可比性规则。** `backend/app.py::compare_saved_experiments` 只交集日期，没有检查 `snapshot_id` 或基础输入/合约定义，也没有确认步骤。隔离探针使用正式与扩展保存记录，接口返回 `comparison_status=REAL_EXPERIMENTS_COMMON_WINDOW` 和 2,220 日数值，没有警告字段。原任务 Gate 2.3.2(3) 明确要求不同 snapshot 默认警告并仅在证明兼容且用户确认后比较；这是可把数据修订误归因于参数的核心风险。
2. **缓存命中未验证阶段产物。** `backend/experiment_runner.py::run` 校验 `result.json` 与 manifest 的身份及 result 摘要，却不复验 `artifact_sha256` 和阶段文件。把一份真实已认证运行的 `result.json`、manifest 拷入隔离临时缓存、不放任何 parquet，重复同配置仍返回 `status=PASS`。后续 `resolve_artifact` 才会拒绝，导致“运行成功”和“保存后可用”冲突。修复范围是让 cache-hit 使用同一完整产物校验，再对外返回 PASS。
3. **自定义评估方案重开后 UI 展示全期指标。** 隔离 SQLite 中保存一份 2020 年评估，`GET saved/{id}` 返回 `evaluation.metrics.observations=243`，但同时保留 `experiment.observations=2670`、全期 history；`frontend/app.js::renderExperimentResults` 优先读取 `r.experiment`，没有按保存评估区间筛选路径。用户重开 2020 方案后看到的是 2,670 日全期 KPI/NAV，虽然标题和元数据说它是 2020 评估。比较 API 对保存区间的交集已修复，但单方案展示仍错。
4. **方案库和运行状态合同未实现。** `SaveExperimentRequest`/SQLite 没有 tags、updated_at 或可编辑元数据；API 只有同步 `POST /api/experiment`、evaluate/save/list/open/compare，没有 `GET run/{id}`、PATCH、DELETE、分页/搜索/标签/快照/状态过滤。FAIL 由 runner 返回但不写入 `experiment_runs`，没有重启后可追踪的 FAILED 状态。任务书 Gate 2.2.2–2.2.5 与 Gate 2.4 将这些列为流程要求，不是建议性的装饰。
5. **Mode B 比较解释和页面结构缺项。** `modeBPageIds=[5]`，四个研究动作塞在单页。前端 A/B 只画 NAV，表中仅年化收益、年化波动、Sharpe、回撤、总成本；没有累计收益、每日收益差、日股票/债券/商品敞口、10VT 路径/边界命中、换手与分层成本路径、贡献、最大差异日点击穿透，也没有独立可比性诊断。后端虽给出三类**平均**敞口与三项**合计**成本，不等于任务书要求的逐日解释。
6. **API 泄露本机绝对路径。** 独立 ASGI `GET /api/experiment/saved/{id}` 返回 `output_path`、`artifact_path`、以本机绝对路径作键的 `source_hashes` 和输入阶段路径；`GET /api/experiment/parameters` 的 `engine` 也为本机路径。前端“实验运行信息”会直接展示路径键。任务书 3.1(10) 明确要求 API 不泄露本机绝对路径。响应应只给稳定的源 ID/相对显示名与摘要，真实路径只保留服务端。
