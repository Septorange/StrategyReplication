# Phase 2 source inventory

The runner uses the immutable V6 Phase3B source (`src/phase3b.py`, config and frozen Python environment), the Phase 2/Phase 3A snapshot inputs, and the adapter modules under `backend/` and `scripts/run_v6_experiment.py`. Published Web/Analytics bundles are read-only reconciliation evidence. Runtime SQLite/cache files stay outside the Git change set.

The exact freeze inventory and aggregate digests are in `V0.7_PHASE2_FROZEN_HASHES_BEFORE.json` and `..._AFTER.json`. The aggregate is computed over sorted relative paths, byte lengths and per-file SHA-256 values.
