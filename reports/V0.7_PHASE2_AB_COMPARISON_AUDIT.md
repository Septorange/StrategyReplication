# A/B comparison audit

Comparison first resolves both saved artifacts and runs the compatibility contract. Same immutable snapshot and certified V6 adapter semantics are comparable. Different snapshots return structured `NOT_COMPARABLE` and no KPI/NAV payload. Same-snapshot comparisons intersect the two saved evaluation windows and actual trading dates, rebase both NAVs from 1, and return average exposures, layered costs, daily 10VT/exposure/cost fields and top return-difference days.

The certified extended 12% and commodity 5bps schemes compare over 2,670 days. Legacy unverified schemes are retained and rejected.
