# Experiment library schema

SQLite remains the durable metadata store with WAL and foreign keys. Existing `experiment_runs`, `experiment_evaluations`, and `saved_experiments` rows are preserved. The idempotent startup migration adds `tags_json`, `updated_at`, and nullable `deleted_at` to saved records; deletion is a soft delete and never deletes shared artifacts. Artifact bytes remain in the controlled local cache and are validated by the full manifest before open/compare.

Public responses expose IDs, snapshot IDs, hashes and safe stage names. Server filesystem paths remain internal.
