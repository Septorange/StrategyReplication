# Phase 2 experiment input mapping

`V6_FORMAL` resolves the frozen V6 Phase2/Phase3A directories. The extended snapshot resolves only a registered `data/v07_local/*/manifest.json` whose `strategy_snapshot_id` matches the request and whose `rebuild_manifest.json` digest matches the registry. The runner then verifies `phase3a/base_target_weights.parquet`, `phase2/signal_returns.parquet`, and `phase2/trade_returns.parquet` against manifest SHA-256 values.

Phase3B functions are called by `scripts/run_v6_experiment.py`; P1–P4 remain locked. No client path is accepted as an input.
