## 阻断项

1. **已保存方案重启后不能重开或比较。** SQLite 的 `scheme_7fa93e41e3524fddadc64e43b5ab4cc6` 指向扩展 12%/5bps 产物 `experiment_cache/9090fd973b5020ae`。该目录及正式方案 `a1b6995475aff04b` 都没有 `artifact_manifest.json`，现存 `result.json` 也没有 `adapter_version`。当前 `resolve_artifact()` 强制要求二者。独立进程内 ASGI 实测：`GET /api/experiment/saved` 返回 200 并把方案列为 `PASS`，但 `GET /api/experiment/saved/{id}` 和两方案 `POST /api/experiment/compare` 均返回 409 `SAVED_SCHEME_ARTIFACT_UNAVAILABLE`。这直接违反已保存扩展 12%/5bps 方案重启重开的验收条件，也使列表的 `PASS` 状态误导用户。位置：`backend/experiment_library.py:145`、`backend/app.py:514`、`:519`、`:538`。旧产物应经有校验的迁移／重跑重新登记，且列表应揭示不可用状态。

2. **A/B 共同窗口忽略各方案已保存的 evaluation。** `compare_saved_experiments()` 只交集两个完整 run 历史，没有把 `a.from_date/to_date`、`b.from_date/to_date` 纳入窗口。用隔离桩将方案 A 的保存评估设为 2020 年、B 设为 2021 年（无重叠），接口仍返回 `2015-09-30`—`2024-11-20` 的 2,220 日共同区间和 KPI。用户看到的结果不属于任一保存方案的评估定义。位置：`backend/app.py:538-576`。需先交集两份保存评估和实际交易日期，再按该区间重算双方指标与 NAV；无交集应明确报错。

3. **比较缺少共同窗口敞口。** 比较只重算 `performance()` 和三项成本，返回的 A/B 指标没有 `avg_equity_exposure`、`avg_bond_exposure`、`avg_commodity_exposure`；前端对比表也仅显示收益、波动、Sharpe、回撤、总成本。与方案比较的敞口要求不符。位置：`backend/app.py:561-573`、`frontend/app.js:504`。

4. **阶段产物缺失仍被声明为真实完整实验。** `resolve_artifact()` 验证 `result.json` 和其摘要，但不检查结果中声明的 `daily_portfolio.parquet`、`final_daily_weights.parquet` 等阶段文件。隔离临时目录只放入身份正确的 result 和 manifest、不放任何阶段 parquet，解析器仍返回 `status=PASS` 且保留三阶段声明。位置：`backend/experiment_library.py:128-183`。缺失／损坏阶段文件须报告明确的不可用状态，或将其从“完整产物”承诺中排除。

## 通过的独立核查

- **扩展默认逐日一致性。** 独立读取默认实验 `3306f126fc096802` 与已发布扩展 Web parquet，规范化日期后，2,670 个组合日及 29,370 个资产日键完全相同。组合毛／换月后／净收益、换月／再平衡／总成本、10VT multiplier，以及资产日初／最终／日末权重和单资产 haircut 的最大绝对差均为 0；净值最大差为 `1.5987e-14`。
- **12%/5bps 历史产物确为 V6 Python 结果，成本没有双扣。** 扩展产物 `9090fd973b5020ae` 的 `engine_run.json` 返回码为 0，日志记录调用 V6 `build_single_asset_vol_control`、`build_execution`、`build_portfolio_daily`；日志中的 V6 `phase3b.py` 和配置哈希与当前冻结文件相符。2,670 日成本合计：合约换月 `0.06971190355`、组合再平衡 `0.02528320554`、总计 `0.09499510909`；逐日 `total = roll + rebalance` 最大残差 `5.1e-20`，`net = after_roll - rebalance` 最大残差 `3.1e-18`。商品交易数据的成本参数均为 5bps，商品原始换月成本合计 `0.2095`。正式 12%/5bps 产物对应 2,220 日，成本恒等式也成立。当前 Python 适配器把 5bps 同时送入商品换月 overlay 与 V6 Phase3B 的商品再平衡成本配置。上述历史产物的身份封装尚不符合当前解析器，不能据此视为生命周期通过。
- **评估边界。** 对现有扩展 run 历史独立调用评估函数：有效的 2020 年交易日区间返回 243 行；非交易日、逆序、超出 `2026-09-24` 的终点均返回 422。实际 API 通过保存后须再复测对应身份链。
- **禁用参数。** P1/P2/P3/P4 和冻结的分位数观察期改值均被 `unsupported()` 拒绝；READY 参数在脚本中映射到相应 V6 函数调用。扩展 loader 校验 registry 的 rebuild manifest 摘要及三个输入文件 SHA-256，实验输出路径位于独立 cache。
- **身份、缓存、SQLite 基础测试。** `tests/test_experiment_library.py` 和 `tests/test_experiment_costs.py` 共 5 项通过；连同 `tests/test_api.py` 共 16 项通过。测试覆盖同身份并发锁、临时目录发布、重复 ID 冲突和 SQLite 重新打开，但没有覆盖现存旧产物迁移、保存 evaluation 对比较的约束或阶段文件缺失。`node --check frontend/app.js`、`git diff --check` 通过；审计结束时仅新增本报告。

完整 `pytest -q` 为 **58 passed, 1 failed**。失败项 `test_required_real_experiments_have_saved_engine_evidence` 用 V0.6 历史证据中的旧适配器源哈希对比当前已改动的适配器文件；本审计未改写历史证据。这是仍需处理的测试门槛，不能计为 Phase 2 全测通过。
