# V0.7 Phase 1.5 — isolated Phase 1 input mapping

The source is the verified local Phase 1 snapshot `v07_extended_10119bd207b16499`, which remains `LOCAL_UNPUBLISHED`. Its inputs and generated Parquet files are ignored by Git. Canonical values must remain Parquet precision; JSON is an API serialization layer only.

Returns use start-of-day holdings. These checks support the mapping, but do not by themselves authorize the browser to select the extension: snapshot-bound services and end-to-end UI switching remain unimplemented.
