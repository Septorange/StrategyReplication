# V0.6 source mapping

All lineage starts with the frozen V6 formal output reconstructed by the already audited V0.5.1 Web Snapshot. V0.6 copies that snapshot into its isolated directory; canonical Parquet retains precision. Exporter source SHA256s and output SHA256s are in `data/v6_analytics/manifest.json`. The serving layer reads full-precision analytics JSON, not old 10-decimal JSONL. No external market API is accessed.

Existing `/api/v6/*` and research endpoints are preserved. Research day/decision/attribution APIs retain their previously audited JSONL snapshot behavior; analytics uses full precision to satisfy the stricter reconciliation contract. The two serve the same frozen observations and engine, with only pre-existing serialization rounding differing.
