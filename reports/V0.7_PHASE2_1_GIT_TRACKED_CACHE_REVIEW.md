# Git tracked cache review

`git ls-files experiment_cache` reports 80 historical files and approximately 52.7 MB. All 80 were already present at Phase 1.5 base `ad55e07`; this remediation added no cache, parquet, sqlite, CSV, market data or credentials. The new `.gitignore` protects future untracked runtime files but cannot remove these historical index entries.

No automatic `git rm --cached`, history rewrite, deletion or push was performed. Public-repository cleanup requires a separate user decision after inspecting the historical files and their publication risk.
