### 2.1 参数3的特殊处理（必须做预检查）

- baseline UI 显示 **20D / 60D 双窗口取最大值（V6 实现）**；
- 高级实验如希望尝试 `[20]`、`[20,60]`、`[10,20,60]`，必须先明确 V6 Phase3A 是否支持无侵入重跑；
- 不支持时仅展示参数说明，控件为 disabled。

### 2.2 参数2-4 的代码能力门槛

这几项影响 Phase3A / 风险预算 / 历史阈值，不能只将用户输入传给 `src/phase3b.py` 并声称策略已经重跑。执行者应：

### 03｜策略胜率测算表：8 个滚动持有期

参考 `03_strategy_win_rate_table.csv` / `build_win_rate_table()`。

固定窗口（**交易日数**）：

```text
日度=1
周度=5
月度=21
季度=63
半年度=126
年度=252
18个月=378
两年度=504
```

**严格沿用参考脚本的重叠窗口定义**：

```python
forward_return[t,h] = NAV[t+h] / NAV[t] - 1
up = count(return > 0)
down = count(return < 0)
win_rate = up / (up + down)
up_avg = mean(returns > 0)
down_avg = mean(returns < 0)
```

`return==0` 从涨跌次数/分母排除；有效起始交易日均可形成滚动窗口，所以这些窗口**高度重叠、非独立样本**，界面提示，不能把“18个月 100%”当作 100% 独立胜率/预测准确率。

输出行：上涨次数 / 下跌次数 / 胜率 / 上涨平均收益 / 下跌平均收益。无下跌样本则 `—` 而不是 0%。

建议增加可选**不重叠窗口**作为独立研究视图，但必须与参考默认口径明显分开，不能偷偷替换。

### 06｜资产大类历史持仓：敞口 + 三类 120D 波动率

参考 `06_class_historical_holdings.png` / `build_class_holdings_chart()`。

左轴：每日 start-of-day **最终名义敞口**，三条实线 `Equity/Bond/Commodity`。注意 Bond 敞口常常 >100%，禁止硬缩放到 100%。

右轴：过去120日**大类日组合收益贡献**滚动年化标准差，三条虚线：

```python
class_return_contrib[t,c] = sum(asset_contribution[t,assets_in_c])
class_vol120[t,c] = class_return_contrib[:,c].rolling(120).std(ddof=1)*sqrt(252)
```

特别标注：**这是大类贡献序列的波动，不是纯资产类别市场收益波动，也不等于风险贡献 RC**。若将来同时提供市场类波动率，必须另选数据源和明确名称。
